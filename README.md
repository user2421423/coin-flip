# Coin Flip

A simple coin flip app, originally built in SwiftUI for macOS, with a web port so it runs in any browser.

**Live:** https://user2421423.github.io/coin-flip/

## Contents

| Path | What it is |
|---|---|
| `index.html` | Web version (HTML/CSS/JS) served by GitHub Pages |
| `macos/` | Original SwiftUI Xcode project — open `Coin Flip.xcodeproj` and press ⌘R |

## How it works

Tap **Flip Coin** → shows "Flipping..." for 1 second → lands on Heads or Tails (50/50). The button is disabled mid-flip.
